# Lossless Scaling Profile Manager — feature reference

Lossless Scaling Profile Manager groups scaling modes, display profiles, and comparison notes in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Scaling modes | Content and resource groups, together with their configuration or organization details. |
| Display profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Comparison notes | A dedicated section for comparison notes and the configuration details associated with that area. |

The project page follows the same section structure.
